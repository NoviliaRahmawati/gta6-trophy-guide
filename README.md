An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, a guide to every trophy in our own words with its sources cited, a roadmap to the platinum, missable flags, kind filters, a spoiler setting, and progress saved in your browser with export and import. Plain static files under `app/` — no build step, no network, no tracking.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080 (Node 22.18+)
```

Open http://localhost:8080 in a desktop browser. Works with the network off.
