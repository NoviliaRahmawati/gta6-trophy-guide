An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy keeps its official name, description and grade, and pairs them with an original, source-cited guide: what the trophy asks for, a suggested order of attack, and a missable warning where the description implies one. Since the game only releases today, strategy text is honest advice derived from the official descriptions — not yet verified in-game — and every fact points back to Exophase or PSNProfiles.

The tracker half saves your progress in the browser: earned checkboxes, PSN-target counters for the 20 trophies PlayStation tracks numerically, per-trophy notes, search and kind/grade filters, a spoiler shield that hides story trophies until you earn them, and export/import of your whole save as a file. A roadmap page lays out the platinum in ordered stages with live progress, a missables page collects every flagged trophy in one place, and a Next-up planner suggests what to do next. Pure static ES modules, no build step, no network at run time.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080 (Node 22.18+)
```
